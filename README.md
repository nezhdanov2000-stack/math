# Математические игры

Интерактивный веб-тренажёр по математике для практики и отработки навыков счёта и работы с дробями.

## Разделы тренажёра

- **Сокращение дробей**
  - Сокращение чисел
  - Вынесение за скобки
- **Сложение и вычитание**
  - Общий знаменатель
  - Большие знаменатели
  - Занять единицу
  - Смешанные числа
  - Дроби с переменными
- **Умножение и деление**
  - Умножение дробей
  - Деление дробей
  - Целое × дробь
  - Смешанные × ÷
- **Уравнения**
  - Пропорции
  - Перенос через «=»

## Запуск

Проект написан на чистом HTML, CSS и JavaScript.
Для запуска откройте файл `index.html` в любом современном веб-браузере.
