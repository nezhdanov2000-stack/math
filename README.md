# Математические игры

Интерактивный веб-тренажёр по математике для практики и отработки навыков счёта и работы с дробями.

## Разделы тренажёра

- **Сокращение дробей**
  - Сокращение чисел
  - Вынесение за скобки
- **Сложение и вычитание**
  - Общий знаменатель
  - Большие знаменатели
  - Занять единицу
  - Смешанные числа
  - Дроби с переменными
- **Умножение и деление**
  - Умножение дробей
  - Деление дробей
  - Целое × дробь
  - Смешанные × ÷
- **Уравнения**
  - Пропорции
  - Перенос через «=»

## Запуск

Проект написан на чистом HTML, CSS и JavaScript.
Для запуска откройте файл `index.html` в любом современном веб-браузере.

## Как устроен код

Сборки нет: `index.html` подключает скрипты по порядку, все модули — IIFE, которые общаются через `window.MG`.

| Файл | Что делает |
|---|---|
| `js/core.js` | Общее ядро: математика (`gcd`, `factorize`…), случайные числа (`ri`, `rnd`, `pick`), анимации (`popIn`, `burst`, `smash`, `rocket`…), FLIP (`snapshot`/`play`), подсказка `hinter(el)`, уровень `levelOf`, штраф `PENALTY`, уборка эффектов `sweepFx()` |
| `js/<инструмент>.js` | Анимации инструментов (`axe`, `bridge`, `conveyor`, `cups`, `fan`, `heli`, `joker`, `rain`, `teeth`, `tread`, `press`, `ice`, `lightning`, `rocket-fx`). Каждый экспортирует `MG.<имя>` с `icon` и функциями анимации |
| `js/tools.js` | Панель инструментов: наборы по режимам (`SETS`), подписи и курсоры (`INFO`), `need`/`auto`/`disable` |
| `js/<режим>.js` | Режимы: `fractions` (cancel), `factor`, `common` (common + big), `borrow`, `mixed`, `br`, `mul`, `div`, `wf` (whole), `mq` (mixmd), `pp` (prop), `sh` (shift). Каждый регистрирует `MG.modes[имя] = { start, skip, stop? }` |
| `js/home.js` | Карта островов (главное меню) |
| `js/app.js` | Переключение карта ↔ режим, хэш в адресе, счётчик «решено» в `localStorage` |
| `sw.js` | Офлайн-кэш (сначала сеть, потом кэш) |

### Правила, которые помогают не ломать игру

- **Асинхронные анимации и «Другая задача».** Каждая длинная функция режима запоминает `const st = state` и после каждого `await` проверяет `if (state !== st) return;` — иначе доигравшая анимация испортит уже новый раунд. Колбэки эффектов (`onSwap`, `onStart`…) проверяют то же самое.
- **Эффекты рисуются в `<body>`** (`position: fixed`). При уходе из режима `app.js` вызывает `MG.sweepFx()` и убирает всё, что не каркас страницы, а у режима может быть `stop()` для своей уборки (вертолёт, выделение).
- **Новый режим:** добавить `<main class="stage" id="mode-имя">` в `index.html`, набор инструментов в `tools.js → SETS`, точку на карте в `home.js → LEVELS`, модуль, регистрирующий `MG.modes.имя`.
- **Релиз:** заменить `?v=N` во всём `index.html` на новое число и `CACHE` в `sw.js` — одной версией для всех файлов.
- `mul.js`, `div.js`, `wf.js`, `mq.js` — почти одинаковые копии одного режима «пара дробей → сокращение». Правка в одном почти наверняка нужна и в остальных (кандидат на объединение в общий движок).
